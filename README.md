# Skills

Личные скиллы для агентов Cursor. В каждом каталоге есть `SKILL.md`: по нему агент понимает, когда скилл применять и как выполнять задачу. Скрипты, если они есть, лежат в `scripts/`.

Чтобы скиллы подхватывались на машине, каталоги должны лежать в `~/.cursor/skills/`.

## Скиллы

### [create-docx](create-docx)

Собирает Word-документ (`.docx`) через `python-docx`: рекомендательные и мотивационные письма, академические тексты. Если есть шаблон, берёт из него поля, шрифт и интервалы. Без шаблона оформляет как академическое письмо.

### [create-tz](create-tz)

Пишет техническое задание по фиксированной структуре: основная информация, бизнес-требования, user stories, архитектура с диаграммами PlantUML, API и схема БД (DBML и DDL из неё). Каркас документа — `TEMPLATE.md`.

### [download-mts-link](download-mts-link)

Скачивает запись занятия с MTS Link / webinar.ru в один MP4 со звуком и отдельные дорожки по людям той же длительности (для Whisper). Не использует пустые audio-only файлы, из-за которых обычная сборка получается без голоса.

### [fix-broken-pdf](fix-broken-pdf)

Восстанавливает текстовый слой PDF, который на экране выглядит нормально, но копируется мусором из-за сломанной кодировки шрифтов, либо является сканом. Скрипт `scripts/fix_pdf.py` распознаёт такие страницы через OCR macOS и кладёт текст невидимым слоем поверх картинки. Исходный файл не перезаписывает.

### [lecture-conspect](lecture-conspect)

Собирает конспект лекции из транскрибации, презентации и исходников кода. Это выправленная запись занятия, а не пересказ: речь лектора и вопросы студентов сохраняются, правятся язык и явные ошибки распознавания.

### [natural-prose](natural-prose)

Пишет деловой и академический русский без типичных оборотов языковых моделей: мотивационные и рекомендательные письма, эссе, сопроводительные тексты. Опирается на факты из запроса и не выдумывает недостающие имена, даты и цифры.
