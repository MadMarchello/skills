# Генерация Word (.docx)

Скилл для сборки готового `.docx`: типографика и поля как у шаблона (если есть), текст из черновика пользователя. Без «украшательств» ради красоты — чистое деловое оформление.

## Процесс

1. **Найти источник текста и шаблон.** Текст — из `.md` / сообщения пользователя. Если указан `.docx`-шаблон — открыть его и снять параметры оформления (поля, шрифт, размеры, выравнивание, отступы, межстрочный интервал). Без шаблона — взять [дефолты академического письма](#дефолты-академического-письма).
2. **Установить `python-docx`**, если нет: `pip install python-docx`.
3. **Собрать документ.** Предпочтительно: открыть шаблон → очистить body (сохранить `sectPr`) → наполнить абзацами с теми же параметрами. Либо создать `Document()` и задать секцию вручную.
4. **Плейсхолдеры.** Неизвестные ФИО/должность/контакты/даты — как в черновике: `[отчество]`, `[должность]` и т.п. Не выдумывать.
5. **Сохранить** рядом с черновиком, осмысленное имя (`04_рекомендация_Ермакова_Самокат.docx`). Временные `_inspect_*.py` / `_create_*.py` удалить после успеха.
6. **Проверить.** Открыть сохранённый файл через `python-docx`, убедиться в числе абзацев, заголовке и читаемой кириллице (вывод в UTF-8 файл или `sys.stdout.reconfigure(encoding="utf-8")`).

## Дефолты академического письма

Опора на шаблон рекомендательного письма (портфолио ВШЭ). Если пользователь дал другой шаблон — его параметры важнее.

| Параметр | Значение |
|----------|----------|
| Страница | A4 (21×29.7 см) |
| Поля | левое 2.5 см, правое 1.5 см, верх/низ 2.0 см |
| Шрифт | Times New Roman, 12 pt (везде, включая `w:rFonts`) |
| Заголовок | «РЕКОМЕНДАЦИЯ» / аналог — 14 pt, **bold**, по центру, `space_after` 12 pt |
| Подзаголовок | italic, 12 pt, по центру, `space_after` 12 pt |
| Текст | по ширине, красная строка 1.25 см, interline 1.1, `space_after` 4 pt |
| Дата / подпись | обычный абзац слева; перед блоком — пустой абзац с `space_after` 6 pt |

## Правила оформления

- Заголовок и подзаголовок — отдельные абзацы; тело — отдельные абзацы по смыслу черновика (не один сплошной блок).
- Кириллица и кавычки-ёлочки «» сохранять как в источнике.
- Не добавлять цвет, таблицы «для красоты», колонтитулы с логотипами, водялы — только если есть в шаблоне или явно просят.
- Блок подписи (ФИО, должность, контакты, дата, «Подпись») — если он есть в черновике; если в шаблоне только дата — можно добавить компактный блок из черновика, не ломая поля/шрифт.
- На Windows пути с кириллицей передавать через `pathlib` / `os.path`; инспекцию шаблона писать в UTF-8 файл, не полагаться на cp1251-консоль.

## Минимальный каркас кода

```python
from docx import Document
from docx.enum.text import WD_ALIGN_PARAGRAPH
from docx.oxml.ns import qn
from docx.shared import Cm, Pt

def set_run_font(run, *, bold=None, italic=None, size_pt=12):
    run.bold = bold
    run.italic = italic
    run.font.size = Pt(size_pt)
    run.font.name = "Times New Roman"
    rPr = run._element.get_or_add_rPr()
    rFonts = rPr.get_or_add_rFonts()
    for attr in ("ascii", "hAnsi", "eastAsia", "cs"):
        rFonts.set(qn(f"w:{attr}"), "Times New Roman")

def clear_body(doc):
    body = doc.element.body
    for child in list(body):
        if child.tag != qn("w:sectPr"):
            body.remove(child)
```

Снимать с шаблона: `section.*.margin`, `paragraph_format` (`space_after`, `first_line_indent`, `line_spacing`), `alignment`, `run.bold/italic/font.size`.

## Чеклист перед выдачей

- [ ] Поля и шрифт совпали с шаблоном (или с дефолтами выше)
- [ ] Заголовок по центру, текст по ширине с красной строкой
- [ ] Плейсхолдеры не заменены выдуманными данными
- [ ] Файл открывается, кириллица на месте
- [ ] Временные скрипты инспекции/сборки удалены
