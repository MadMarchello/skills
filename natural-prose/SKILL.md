# Живой деловой текст

Опора на практику из писем портфолио ВШЭ: ритм, конкретика и вычитка маркеров — не «humanizer-промпт».

Гарантии «0% на GPTZero» нет. Цель — текст, который читается как написанный человеком с фактами пользователя, а не как типовой LLM-эссе.

## Процесс

1. **Собрать якоря.** Реальные факты: роли, проекты, артефакты, даты, цифры, имена. Не выдумывать. Неизвестное — плейсхолдер `[...]`.
2. **Черновик по жанру.** Мотивационное — от «я»; рекомендация — от голоса рекомендующего; эссе/сопровод — по заданной структуре. Без вступления «в современном мире» и без финала «таким образом / в заключение».
3. **Развести голоса.** Если несколько текстов в одном пакете — разные фокусы и лексика; не копировать абзацы между файлами.
4. **Анти-LLM проход.** Пройти чеклист ниже (и [markers.md](markers.md)). Поправить ритм и маркеры до выдачи.
5. **Выдать результат.** Готовый текст; при черновиках для согласования — HTML-комментарий `<!-- TODO -->` с плейсхолдерами в конце файла, не в теле для комиссии.

## Правила стиля

- **Ритм (burstiness):** короткие фразы рядом с длинными; разная длина абзацев; без симметричных троек («гибкость, скорость и качество»).
- **Конкретика:** названия ролей, проектов, артефактов, одна рабочая/неприятная деталь на текст — вместо «высокий уровень компетенций».
- **Живой деловой русский:** можно сдержанная разговорность в мотивационном; в рекомендации — ровный деловой тон без лозунгов и без контрастных цитат в кавычках ради «драйва».
- **После черновика** — явная правка под живой слог, не отправка первого прохода модели.

## Чеклист перед выдачей

- [ ] Нет русских GPT-маркеров из [markers.md](markers.md)
- [ ] Нет симметричных списков из 3 прилагательных/существительных подряд
- [ ] Есть конкретные факты пользователя (не общие формулировки)
- [ ] Длина предложений и абзацев заметно варьируется
- [ ] Нет финала «таким образом / в заключение / подводя итог»
- [ ] При нескольких текстах — разные голоса, без копипаста абзацев
- [ ] Неизвестные данные — плейсхолдеры, не выдуманные факты

## Жанры (кратко)

| Жанр | Вход | Структура |
|------|------|-----------|
| Мотивационное | цель программы, опыт, 1–2 личных якоря | вход из практики → траектория с фактами → связка с программой → конкретная цель |
| Рекомендация | кто рекомендует, как знаком, 1–2 результата | кто я → как знаком → сильные стороны с фактами → готов ответить |
| Эссе / сопровод | тезис, факты, ограничения объёма | тезис сразу → развитие фактами → вывод без канцелярского резюме |
