# Маркеры LLM-слога (русский)

Вырезать или перефразировать при анти-LLM проходе.

## Канцелярит и «эссе-GPT»

- является / являются
- данный / данная / данное / данные (в значении «этот»)
- стоит отметить / следует отметить
- важно понимать / важно отметить
- в современном мире / в современном обществе
- кардинально трансформирует / играет ключевую роль
- неотъемлемой частью
- безусловно / несомненно
- комплексный подход / высококачественный
- в рамках (если можно сказать проще)
- осуществление / реализация внедрения (номинализации вместо глагола)
- подчеркивает / подчёркивает значимость
- ключевой / ключевые (как наполнитель)

## Финалы-штампы

- таким образом
- в заключение
- подводя итог
- резюмируя вышесказанное

## Ритмические ловушки

- Тройки: «X, Y и Z» с тремя абстрактными существительными подряд
- Одинаковая длина всех предложений в абзаце
- Три абзаца одной длины подряд
- Цепочки род. падежа из 3+ существительных («процесс обеспечения повышения качества…»)

## Чем заменить

| Плохо | Лучше |
|-------|--------|
| является важным фактором | влияет на… / без этого не… |
| данный кандидат обладает | он / она + конкретное действие |
| стоит отметить, что | просто сказать факт |
| в современном мире ИИ | с практики / с проекта X |
| осуществление внедрения | внедрил / внедрили |
| комплексный подход к задаче | что именно сделал по шагам |
